Design Notes

Auth Modes Three tiers via env vars: open access (dev/demo), API key (X-API-Key header), full JWT with roles (viewer / analyst / supervisor). Frontend auto-detects mode from GET /api/v1/health.
NLP Pipeline User types plain-language task description. spaCy tokenizes and extracts keywords. thefuzz fuzzy-matches against the hazard catalog and work types to pick the recommendation path.
SQLite Limitations Single-file DB, good for demo. Schema auto-migrates at startup. check_same_thread=False required for FastAPI's thread pool. Swap for PostgreSQL before production.
Tinker Form Integration 17 procedural controls from the official Tinker AFB Risk Assessment Form are mapped 1:1 to hazard IDs. Badged as TINKER AFB FORM in all three result panels.
